# systemset — настройки системы Q2/A13

Папка с простыми `*.conf`-файлами для настройки приставки «на месте», без
пересборки. Каждый файл — обычный текст с закомментированными примерами.

Расположение на карте: **`/flash/systemset/`** — загрузочный раздел Lakka `p1`
(в Windows — `E:\systemset`). На разделе с ромами (`/storage`, `p3`, `F:`) этих
файлов быть НЕ должно. Файлы читаются нашим init (`a13init`) при загрузке.

| Файл | Назначение |
|------|------------|
| `usb.conf`     | режим USB: `console` (консоль) ИЛИ `storage` (флешка) ИЛИ `off` — **не вместе** |
| `log.conf`     | включение/выключение логов (`RETRO.LOG`, `RA.LOG`, `retroarch.log`) |
| `display.conf` | что показывать при загрузке: `logo` / `console` / `off` |
| `key.conf`     | переназначение кнопок (действие = пин SoC) |
| `system.conf`  | CPU (МГц/губернатор), zram-swap, hostname |
| `audio.conf`   | ALSA-устройство, громкость |

## Формат
- `ключ = значение`, по одному на строку.
- Строки, начинающиеся с `#`, игнорируются (комментарии/примеры).
- Если файла нет или ключ не задан — используется значение по умолчанию.

## Важно
- **`usb.conf`: консоль и massa-сторедж нельзя одновременно** — вендорский UDC
  на A13 из-за этого «дёргает» USB и консоль отваливается.
- При прошивке «с нуля» раздел `/storage` пересоздаётся — эту папку нужно
  положить заново (или она должна входить в образ/копироваться init’ом).

## Статус
Файлы-шаблоны созданы. Чтение их в `a13init` — следующая задача (init пока не
разбирает эти конфиги; можно вшить значения по умолчанию из этих примеров).
